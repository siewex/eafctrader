# FUT Market Bot — сигналы о просадках цен EA FC (ПК) в Telegram

Раз в пару минут опрашивает цены всех торгуемых карт рейтинга 84+ (≈500 карт) на **FUTNext** и присылает в личку каждому, кто нажал `/start`, те, что резко упали ниже рыночной цены — с расчётом профита после налога EA 5%. Опционально дублирует в канал.

Почему FUTNext, а не Futbin: у Futbin и fut.gg стоит Cloudflare-защита, которая режет любые автоматические запросы (даже из headless-браузера). У FUTNext открытый JSON API без ключей, ПК и консоли — отдельные рынки. Единственное, чего там нет, — списка последних продаж как у Futbin; вместо него в посте почасовая история минимальной цены.

## Как выглядит пост
```
Jude Bellingham Common 90 CAM · PC

Новая цена: 237,150 💰
Профит: 15,075 📈 (после налога 5%)

Изменение: -10.68% 🔻 (к рыночной)
За последний час: -15.0% (было 279,000)
Обновлено: 2 мин назад

Рыночная цена: 265,500 💰 (медиана 24ч)

Мин. цена по часам (UTC±0:00) ⏱
   271,000  2026-09-22 09:00
   275,000  2026-09-22 08:00
   ...
```
Плюс фото игрока, и ниже два блока: **последние замеры минимального лота** (наши, каждые ~2 мин — аналог «последних продаж» Futbin) и минимальная цена по часам.

### Одиночный лот vs движение рынка
Списка реальных продаж, как у Futbin, ни у кого в открытом доступе нет. Но у FUTNext в часовой истории есть `averagePrice` — средняя по замерам минимального лота за час. В норме она совпадает с минимумом (разрыв ~1%). Если кто-то один выставил карту за 31 при рынке 40, текущая цена окажется сильно ниже средней за час — бот ставит пометку **«⚠️ Похоже на одиночный лот»** и показывает среднюю, чтобы читатель не выставлял свою карту по 31. Порог — `FUT_SINGLE_LOT_GAP` (10%), `FUT_SKIP_SINGLE_LOT=1` — вообще не постить такие.

Оговорка: FUTNext обновляет цену раз в несколько минут, и одиночный лот с −20% к моменту поста почти наверняка уже купили. Бот сильнее в реальных движениях рынка, чем в снайпе отдельных лотов.

## Когда бот постит
Все условия сразу (числа — по умолчанию, меняются в `.env`):
1. цена лота не старше 30 мин и не ниже 5 000 монет;
2. цена ниже **рыночной** на 8%+ — рыночная = медиана минимальных цен за 24 ч (часы, когда карты не было в продаже, не считаются);
3. профит после налога 5% от рыночной ≥ 1 000;
4. спад **свежий**: цена ниже максимума за последний час на 5%+ — иначе бот бы постил карты, которые просто давно стоят дёшево;
5. антиспам: одна карта не чаще раза в 3 часа, кроме случая, когда она упала ещё на 5%+ от прошлого поста.

## Структура
```
main.py       — Telegram-бот, циклы опроса и обновления watchlist
futnext.py    — клиент API FUTNext
detector.py   — логика сигнала
formatter.py  — текст поста
storage.py    — SQLite: watchlist, снимки цен, отправленные сигналы
config.py     — настройки из окружения
```

## Запуск
1. @BotFather → `/newbot` → токен.
2. `cp .env.example .env`, заполнить `BOT_TOKEN` (и `ADMIN_IDS` — свой user_id, узнать через `/id`).
3. Запустить, написать боту `/start` — с этого момента сигналы приходят в этот чат. Подписаться может любой, кто напишет `/start`; `/stop` — отписаться. Если нужен ещё и канал — задать `CHANNEL_ID` и сделать бота его админом.
4. Локально:
```
pip install -r requirements.txt
python main.py
```
При старте бот сам соберёт watchlist (~3 сек) и начнёт опрос. В логах: `Watchlist обновлён: ...`, затем каждый круг `Круг N: 523 карт за 32 с, ошибок 0, сигналов 2, отправлено 2`.

Первый круг после запуска может дать несколько постов сразу — это карты, упавшие за последние 2 часа по истории FUTNext. Дальше только новые падения.

## Деплой на Bothost
Как и MEGA-бот: тип Python, главный файл `main.py`, переменные из `.env.example` задать в панели (`.env` не загружать). База `market.db` создаётся сама рядом с `main.py`.

## Команды
Всем: `/start` — подписаться, `/stop` — отписаться, `/price <имя>` — текущая цена карты из watchlist с историей, `/id`, `/help`.

Админам (`ADMIN_IDS`): `/status`, `/refresh` (пересобрать watchlist), `/watch <id или ссылка futnext.com/players/…>` (добавить карту любого рейтинга вручную), `/unwatch <id>`, `/test [id]` — прислать пример поста, чтобы проверить формат.

## Нагрузка на FUTNext
Круг = 1 запрос на карту (~5 запросов/сек при `FUT_CONCURRENCY=4`) + история раз в час на карту. Watchlist пересобирается раз в 12 часов (~16 запросов). Лимитов и банов при таком темпе не замечено, но `FUT_CONCURRENCY` выше 5 ставить не стоит.
